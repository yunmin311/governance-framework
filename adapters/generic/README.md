# 通用对话平台适配

## 适用范围

适用于不能自动读取本地 `CLAUDE.md`/`AGENTS.md`、没有 Skill 安装或没有文件权限控制的普通聊天平台。

## 上下文加载

使用完整启动 Prompt，加上任务真正需要的文件或摘录。不要把整套手册和所有项目聊天一次性塞给每个对话。最小输入顺序：治理模式、用户 Profile 摘要、稳定 `project_id`、当前机器绑定、对应项目 adapter、项目正本的可追溯摘录、角色卡、任务包、输出位置。

平台无法访问本地文件时，必须由提供材料的人明确给出版本和来源；AI 不能声称自己已读取电脑上的路径。不能访问的事实标 `UNKNOWN`。项目绑定不完整时保持 `DISCOVERY-READ-ONLY`，不得替用其他项目的 adapter 或旧电脑路径。

## 机械约束

Prompt 只能影响回答，不能构成机械约束。通用聊天平台没有本机 Hook、Rules 或 permissions 时，`hard_enforcement` 固定为 `NOT_AVAILABLE`。危险操作必须由外围工具、人工门禁或受控执行环境处理。

## 最小验证

1. 让新对话列出实际收到的文件和版本；
2. 放入一个互相冲突的候选与批准件，确认它按状态和权威顺序处理；
3. 要求它说明哪些动作需要外部执行或用户批准；
4. 确认最终回执包含产物内容、来源和下一步，而不是伪造本地路径。

## 失败处理

出现失忆或漂移时重新发送最小启动块和当前任务来源，不追加越来越长的聊天补丁。若任务依赖本地写入或机械阻断，迁移到具备对应工具的平台执行。
