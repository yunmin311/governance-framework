HTML 输出任务——开工、实现与验收提示词

适用对象：设计对话、主对话、顾问对话、笔记对话，以及任何需要生成 HTML 的 AI。

把以下正文连同项目正本、当前任务和必要来源发给执行对话。不要只发本提示词而不给项目证据。

============================================================
提示词正文
============================================================

你即将执行一个 HTML 输出任务。HTML 能打开不等于任务完成；你必须同时保证内容正确、结构完整、视觉一致、来源可追溯和文件可交付。

一、先确认角色

从以下角色中选择当前角色，并声明权限：
- 设计：执行页面与组件设计；不能自行解除冻结或改变整体艺术方向。
- 主对话：把已批准内容与设计落实成可运行实现；不能用技术便利性重写设计。
- 顾问：生成分析、比较、风险或汇报页面；必须区分事实、判断、建议和未知。
- 笔记：生成阅读、索引或知识页面；不能为了视觉完整补写事实和来源。
- 其他：写明职责、授权和禁止项。

同一对话承担多个角色时分阶段声明。探索、执行、评审、批准和冻结不能由同一角色自动连成一条自我批准链。

二、Gate H0：开工回执

生成任何完整 HTML 前先输出：
1. 项目实际路径和唯一正本。
2. 实际读取的项目宪章、设计基线、版本、当前 Spec 和来源文件。
3. 无法读取的内容，统一标记 UNKNOWN。
4. 输出类型：设计候选、可运行实现、顾问报告或笔记页面。
5. 目标页面、模块、状态和响应式宽度。
6. 沿用规则、允许探索和禁止改变项。
7. 文件落位计划：output_root、计划创建或修改的文件、canonical_outputs、temporary_outputs、Review 位置和回滚点。

如果项目已经有目录和命名规范，优先沿用。不要默认写入桌面；不要因为中文路径处理失败而静默改存其他位置。

普通低风险的新建文件可在报告计划后继续；如果要修改既有目录、覆盖同名文件、迁移文件或建立新的长期根目录，必须等待用户批准。

三、Gate H1：完整骨架

编码前建立覆盖表，逐项列出：
- 页面或长页面区段；
- 目的和内容来源；
- 首屏、中段和尾部模块；
- 空、加载、错误、长文本和极端数据状态；
- 桌面、中间和移动宽度；
- 共享组件与专用组件；
- 预期验证方法。

不得使用“后续类似”“其他模块同上”跳过尾部规划。

四、Gate H2：设计系统

先定位项目已有 Token、CSS 变量、组件规则和字体资产。集中复用字体、颜色、间距、内容宽度、圆角、边框、阴影、纹理、图标、动效和组件状态。

每项设计标记：
- INHERITED：沿用冻结规则；
- ADAPTED：基于规则适配内容；
- EXPLORE：新探索，尚未批准；
- EXCEPTION：有证据的例外。

不要在后半段复制一套近似 CSS，不要为了赶进度把不同模块全部改成默认卡片。

五、Gate H3：实现与完整度

按覆盖表逐项实现。每完成一个页面或长页面区段，就检查：
- 内容是否完整且来源正确；
- 信息层级、密度、留白和对齐是否与基线一致；
- 重复组件是否真正复用；
- 尾部是否与首屏保持同等级设计投入；
- 响应式、长文本、空状态和错误状态是否存在；
- 图片、图表、字体、链接和交互是否真实可用；
- 是否残留占位文本、假数据、无效链接或未授权素材。

发现跨模块漂移时停止继续扩写，进入 C2 BASELINE-RESET。发现虚构来源、权限越界或覆盖风险时进入 C3 INCIDENT(READ-ONLY)。

六、Gate H4：实际渲染

平台能力允许时必须实际打开或渲染 HTML。至少检查：
- 桌面宽度；
- 移动宽度；
- 关键项目的中间宽度；
- 全部目标页面或长页面全部区段；
- 字体加载、图片、链接、滚动、溢出、固定元素和交互状态。

不得只检查源码或一张精选首屏截图。没有实际渲染的视觉结果标记 UNVERIFIED。

七、最终文件 Review

完成后必须给出：
1. 实际读取、创建、修改、移动的文件及准确路径。
2. 未执行的删除和所有 DELETE-CANDIDATE。
3. 每个交付物的用途、状态、打开方式和唯一正本。
4. 外部链接的标题、平台、访问范围、生成时间和本地索引。
5. 覆盖表中每一项的检查结果。
6. 实际渲染范围、发现的问题和修复结果。
7. 与基线的差异、仍未验证项和需要用户决定的事项。
8. 回滚点和下一步安全动作。

只有同时通过内容、结构、视觉、来源和文件 Gate，才能说“达到当前任务完成标准”。自检不能替代用户对艺术方向的最终批准。

最终回复不能只给链接，不能只说“文件在桌面”，也不能要求用户自己搜索。
