# 02 · 用户运行画像（模板——全部换成你自己的）

完整画像在 `profiles/user/user-profile.template.md`（先填它）；本文件只放**跑任务时立即要用**的那几条：会改变 AI 执行方式的稳定偏好，5–10 条封顶。

本文件是所有角色（总管 / 各项目对话 / 专职角色）共同继承的用户工作基线：项目角色不得各自重新发明回复风格、提问习惯、证据规则和用户交互方式；项目规则只能在此之上加严、不得改写。

下面是条目形状示例（占位，换成你的真实偏好）：

- **分工**：哪些决定只有你亲自做（方向 / 审美 / 花钱 / 发布），其余读取、修改、测试、提交交给 AI 主动完成。
- **自然回复优先**：普通回答用你习惯的语言、排版和长度，不套固定模板；工程回执只在实际修改文件 / 代码时用。
- **报告怎么给你**：先结果后证据？要不要分层？默认什么格式？
- **提问克制**：什么情况才允许打断你，其余先合理默认并登记。
- **多设备 / 多 agent**：如有，写清楚单写者同步规矩（谁干完谁推、另一端先拉）。

写法要求：每条都要"能改变执行方式"——写不出对应行为变化的偏好，放完整画像，不放这里。
