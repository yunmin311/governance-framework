# 00 · 运行入口（普通任务先读这一份，别通读治理库）

你在处理一个具体任务，不是审计整套治理系统。先用本文件把任务分类，再按 `runtime/router.yaml` 只加载该模式列出的文件。文件存在不等于要读它。

## 第一步 · 判定任务模式

- **QUICK**：改一个已知文件、小修文案或格式、单点问答。可回滚、地盘清楚。
- **NORMAL**：某个已治理项目内的常规代码或内容任务，需要项目正本与直接相关 Spec / 测试。
- **STRUCTURAL**：新电脑首次接入、换机重绑路径、跨项目结构调整、宪章级改动。
- **INCIDENT**：正本冲突、越权写入、私密外泄风险、多对话现状互斥。

拿不准就取写入面更小的一档：QUICK 与 NORMAL 之间按 NORMAL 之下限起步；一旦涉及不可逆、越权或私密风险，直接 INCIDENT。

## 第二步 · 只加载 router 指定的文件

按 `runtime/router.yaml` 中当前模式的 `default_files` 读取。默认预算：治理文件不超过 **5 个**、合计不超过 **8000 字符**。需要更多来源时，先升级模式再加载，不在原模式里偷偷扩读。

## 第三步 · 默认不读（除非 router 明确要求）

`archive/`、`docs/`、`reviews/`、`published/`、`releases/`，以及任何 PDF、DOCX、ZIP 正文；完整宪章正文、完整用户 Profile、全部机器发现资料、全部 `references/`、全部 `templates/`、历史 reviews。

不得把“为了安全或完整”理解成递归通读整个仓库。QUICK 与 NORMAL **不得**默认加载上述内容。

## 升级触发

出现下列任一项，立即升级模式并重新按 router 加载：跨项目影响、改结构或数据结构、动 Git 历史或硬权限、公开发布、真实花钱、来源冲突无法用证据解决、需要用户不可逆决定。→ 归入 STRUCTURAL 或 INCIDENT。
