# INBOX · {{PROJECT_NAME}}

> 这个项目的收件箱。**只收三类**,别把它当项目管理平台,也别当 agent 之间的消息总线。
>
> | 收 | 不收 |
> |---|---|
> | `blocked` 卡住了,需要外部条件才能继续 | agent 之间的即时消息(走 harness 原生的 task / message) |
> | `needs-user` 要用户看或拍板 | 项目状态(状态的正本是 Git / 测试 / Spec / 项目文件) |
> | `resume-later` 以后的会话要记得接着做 | 会议记录、日志、总结 |
>
> 格式一行一条:`- [ ] 日期 · 谁 · 什么事 · 状态`
> 处理完把 `[ ]` 改成 `[x]` 并挪到【已归档】。
>
> **升级规则**:真正需要用户跨项目决策的,除了留在这里,再往全局收件箱
> `<GLOBAL_INBOX>` 顶部加一行,注明来自哪个项目。全局那份只管用户级决策与通知。
>
> `<GLOBAL_INBOX>` 由你的 Personal Overlay 解析(通常是你私有治理仓根的 `INBOX.md`)。
> 公开框架不知道、也不该知道你的私有仓叫什么名字——**别把某个具体仓名写死进模板**。
