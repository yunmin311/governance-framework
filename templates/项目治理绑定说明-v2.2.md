# 项目治理绑定说明 v2.2

本模板供项目自己的 `AGENTS.md`、`CLAUDE.md` 或等价入口引用。它连接全局治理与项目正本，但不复制任何一方的全文。

```text
project_id: PROJECT_ID

开工前必须：
1. 从当前设备已验证配置解析 governance_root，不猜盘符。
2. 读取治理内核和用户 Profile。
3. 读取当前机器 Profile 的 project_bindings[PROJECT_ID]。
4. 读取 projects/instances/PROJECT_ID.adapter.yaml。
5. 读取 adapter 指向的项目唯一规则文件。
6. 声明当前角色、读写范围、Git 所有权、输出位置和验证方式。

绑定或项目正本不可达时保持 DISCOVERY-READ-ONLY，不执行项目写入。
项目事实仍只在项目仓库自己的唯一规则文件中维护。
```

把模板写入真实项目属于跨项目写入，必须逐项目取得用户授权；发现项目或生成候选绑定不构成授权。
