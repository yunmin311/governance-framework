# 设计系统恢复与冻结规范

**目的：** 让设计质量依赖可复现的方法和基线，而不是某个长对话是否还记得最初发生了什么。

---

## 1. 设计目录的最小结构

每个长期设计项目应按实际情况映射以下逻辑文件；已有等价正本时只登记，不重复创建：

```text
DESIGN_CHARTER          设计职责、权限和评审规则
REFERENCE_ANALYSIS      参考来源与完整拆解
DESIGN_BASELINE         已批准艺术方向与版本
DESIGN_SYSTEM           颜色、字体、间距、圆角、阴影、纹理
COMPONENT_RULES         组件结构、状态和使用规则
MOTION_RULES            动效原则与参数（适用时）
DESIGN_DECISIONS        已批准设计决定
REJECTED_DIRECTIONS     已否决方向及原因
CURRENT_DESIGN_TASK     当前任务、基线和允许探索范围
APPROVED_OUTPUTS        已批准产物索引
archive                 历史版本
```

## 2. 每次设计任务的强制读取

设计角色开始工作前依次确认：

1. 项目唯一正本。
2. 设计职责和文件所有权。
3. 当前设计基线及版本。
4. 原始参考分析。
5. 设计系统和组件规则。
6. 已批准决定与被否决方向。
7. 当前设计任务。
8. 当前页面代码或实际实现。

回执中必须列出实际读取项。无法读取时暂停重新定义艺术方向。

## 3. 网站视觉拆解标准流程

### 3.1 建立证据快照

记录 URL、访问日期、页面范围、屏幕宽度、登录状态、截图或离线快照。动态网站必须注明哪些内容可能随时间变化。

### 3.2 分离结构与表象

结构层分析：页面区域、网格、阅读顺序、内容密度、对齐、响应式变化。  
表象层分析：字体、颜色、圆角、边框、阴影、纹理、图标和动效。

### 3.3 提取可验证数值

优先读取实际 CSS、计算样式、字体信息和资源，而不是只凭截图估计。每个数值记录来源；无法精确时写估算范围和置信度。

### 3.4 分析关系而不是罗列属性

解释为什么大留白、强字级、弱边框或特定色阶能够共同形成某种感受。单独复制一个颜色不会自动复制艺术方向。

### 3.5 区分借鉴与照搬

列出：可以迁移的原则、需要适配的模式、禁止直接复制的品牌资产或商业字体、与本项目目标不相符的部分。

### 3.6 转换为本项目规则

把参考分析变成项目自己的 Token、组件规则、版式限制和验证案例。每项规则说明来源与适配理由。

### 3.7 制作候选和对照

候选方案必须与当前基线并排比较，标出沿用、变化、影响面和回滚路径。不要只展示新方案。

### 3.8 冻结与再调用

用户确认后写入设计决策，记录版本、日期、决定者、源文件和验证证据。后续任务读取冻结基线，不重新从模糊风格描述开始。

## 4. 三类设计角色

### 设计中枢

维护设计真相源、版本、任务分配、跨页面一致性、评审记录和候选提交。它不能因为管理设计而跳过用户最终审美决定。

### 设计执行

按当前基线完成具体页面；输出中区分“沿用规则”和“新增探索”；不能自行宣布设计最终确认。

### 设计辅助

负责参考收集、局部尝试、可访问性检查、视觉差异、技术可行性和实现辅助；不能改变整体艺术方向。

如果一个项目只有一个设计对话，可以让它承担多项工作，但在同一次任务中仍要显式区分探索、执行和评审阶段，避免自我批准。

## 7. 冻结条件

设计只有同时满足以下条件才能转为 `FROZEN`：

- 有明确源文件和版本。
- 有可复现的生成或打开方式。
- 用户或授权角色已确认。
- 与现有设计系统差异已记录。
- 被否决方案已记录。
- 关键字体、图片和资产许可已检查。
- 有与实际实现的验收方法。
- 有回滚点。

没有变更请求的新设计不能覆盖冻结基线。

## 9. 一致性检查

设计中枢或总管 AI 在汇报前检查：

- 当前产物是否引用同一基线版本。
- Token、字体、色阶、圆角、纹理和组件状态是否一致。
- 是否出现“同名 final 文件”而没有版本号。
- 设计稿、实现和汇报截图是否来自同一阶段。
- 是否把局部探索误称为整体改版。
- 是否重新引入已否决方向。
- 是否有商业字体、素材授权或跨设备缺失问题。

## 10. 设计能力恢复完成标准

- 原始参考来源或可替代证据已找到。
- 网站拆解步骤已经写成可复用流程。
- 设计基线、源文件和版本明确。
- 设计角色边界得到用户确认。
- 至少用一个真实页面验证新对话可以读取基线并稳定复现。
- 新对话无法读取来源时会停下，而不是重新发明。
