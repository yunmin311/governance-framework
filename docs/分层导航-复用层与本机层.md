# 分层导航:复用流程 vs 本机适配

> 本仓库 = **复用流程(通用方法)**。你的**本机适配(机器路径、花名册、git 身份、项目绑定)**不在这里——
> 它们属于你自己的私有实例仓。两层永远分开维护。

## 一个万能测试

遇到任何一条,问:**「这条,拿到另一台电脑还成立吗?」**
- 还成立 → 复用流程(在本框架里,换机不改)
- 不成立、要重查 → 本机适配(去你的私有实例仓填)

## 复用流程(本框架)
- `core/` 宪章 · `runtime/` 承重规则与路由 · `profiles/user/` 用户画像**模板**
- `templates/` · `skills/` · `adapters/` · `launchers/` · `docs/` · `tools/` 校验器

## 本机适配(不在本框架,去你的私有仓)
- 机器 Profile 实例(盘符、花名册、平台能力)
- 项目 adapter 实例(某项目 → 某本机路径)
- 来源证据、逐对话身份卡

换电脑:带走本框架,用模板重填本机事实到你的私有仓,永不把本机盘符/身份写进本框架。
