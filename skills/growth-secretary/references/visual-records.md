# 可视化记录 · Visual Records

复盘和记忆不一定只是文字。适合"记录类"的东西——一段时间里发生了什么、偏好怎么分布、习惯怎么变——用图往往一眼就懂。这一层负责把这些出成图。

> **边界(硬)**:本层**只用于生成图表**(记录类数据可视化:时间线 / 分布 / 看板 / 状态轴)。**不用于一般设计、UI、页面、组件、动效**——那些走 `design-method` skill + 它的 `design-resources.md` 货架,别拿 lieflat / 本层去干设计的活。

规矩不变：**只读记忆、只提议画像，图只是把复盘讲清楚的手段，不替代用户批准。**

## 什么时候出图
- 周复盘/月复盘：这段时间的活动、卡点、成长点。
- 记忆盘点：偏好分布、主题占比、记忆增长。
- 决策与踩坑的时间线。
用户随口说"复盘出个图""可视化一下这段时间"也触发。

## 适合记录类的图型
- **活动时间线 / 记忆增长**：折线或面积图，看趋势。
- **偏好聚类 / 主题占比**：条形图或树状图，看分布。
- **复盘看板**：几张小图并排，一屏看完（已验证 / 建议 / 待你决定 各一块）。
- **决策·踩坑时间轴**：按时间排的事件条。

## 怎么渲染：用 lieflat-charts
出图交给 `lieflat-charts` 这个 skill（给 AI agent 用的出图 skill，输出静态 HTML，SVG / ECharts）。装一次：
```
npx skills add https://github.com/larashero3-dotcom/lieflat-charts
```
调用时说清数据和用途，并**指定青瓷蓝配色**，例如：
> 把这份复盘数据做成图，用青瓷蓝（Porcelain）那套配色，一屏能读完。

## 配色：青瓷蓝（Porcelain），钉死
无论用不用 lieflat-charts，图都走这一套单色蓝阶（用户点名的"那个蓝"）。**一张图或一组图只用这一个色系**，不要再混别的颜色。

| 用途 | 值 |
|---|---|
| 纸底 / 背景 | `#F7F2EB` |
| 主文字 / 最深 | `#081F5C` |
| 数据·中 | `#334EAC` |
| 数据·浅 / 强调 | `#7096D1` |
| 最浅 / 淡填充 | `#BAD6EB` |
| 有序数据的蓝阶（深→浅） | `#081F5C` → `#334EAC` → `#7096D1` → `#BAD6EB` |
| 网格线 | `rgba(8,31,92,.16)` |

直接可用的 CSS 变量：
```css
:root{
  --bg:#F7F2EB; --ink:#081F5C; --data:#334EAC; --data-2:#7096D1;
  --faint:#BAD6EB; --grid:rgba(8,31,92,.16);
}
```

## 落位（照画像第 10 节：交付要能打开、别乱堆）
- 图是**静态 HTML**，放复盘工作区，给用户绝对路径能直接打开。
- 复盘产出的图属内部记录，**不进公开仓**，也不当成正式交付物冒充手册。
- 图讲的结论仍要落成文字记忆原子，别只留图（防"图在人走、结论没沉淀"）。

## 教程：实际出一张（照这个走）
触发词：用户说"复盘出个图""可视化一下这段时间""来张记录图"。

**第 1 步 · 定数据和图型。** 从记忆/回执里取**真实**数据（别编），挑最合适的图型（见上"适合记录类的图型"）。一张图只讲一件事。

**第 2 步 · 出图，二选一。**
- **A（装了 lieflat-charts 时）**：跟它说清数据 + 用途 + "用青瓷蓝（Porcelain）那套配色"。安装：`npx skills add https://github.com/larashero3-dotcom/lieflat-charts`。
- **B（保底，任何环境都行）**：直接写一份静态 HTML，配色用上面钉死的青瓷蓝 CSS 变量；要给用户看预览就用无头 Edge 渲成 PNG（跟框架 `tools/render_diagrams.ps1` 同一套）：
  ```powershell
  & "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" `
    --headless=new --disable-gpu --hide-scrollbars `
    --force-device-scale-factor=2 --window-size=<宽>,<高> `
    --user-data-dir=<临时目录> --screenshot=<out.png> <html 的 file:/// 地址>
  ```
  窗口尺寸必须和 HTML 里那张卡片的固定尺寸一致，否则右/下会出白边（这条坑见 `render_diagrams.ps1` 注释）。

**第 3 步 · 落位。** 图放复盘工作区（Obsidian 里能读），给用户绝对路径。不进公开仓、不当正式手册；图讲的结论仍落成文字原子。

**做过的例子**：“治理系统·本轮进度记录”（4 个关键数 + 6 节点时间线，暖纸底 `#F7F2EB` + 靛蓝阶，末节点加圈强调），就是照 B 出的。
