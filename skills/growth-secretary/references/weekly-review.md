# 周复盘仪式

节奏:每周一次,或用户说“复盘一下 / 总结这段时间”。大会话后可做一次轻量“就地沉淀”。

## 步骤
1. **收集**:读这段时间的 L1 原子、`daily/`、各对话回执。
2. **综合**(Generative Agents 式反思):聚类,找出——反复出现的偏好、反复踩的坑、成长点、以及跟现画像矛盾的地方。
3. **提议三样**:
   - **画像 delta**:值得升为 L3 稳定模式的新偏好(需重复出现,非单次)。
   - **skill 候选**:某套打法已被真实任务验证、可复用 → 提议蒸馏成 skill(交给专职蒸馏流程 / 用户批准)。
   - **该删的糟粕**:过期、已被推翻、噪音的记忆 → 提议删 / 归档。
4. **多轮 clarify**:跟用户逐条确认,取精华去糟粕;有分歧就问,不自作主张。
5. **批准后写入**:用户批准的 delta 才写进 L3 画像 + 记忆;被否的记一句“考虑过、否决”,别下周又冒出来。

## 报告格式
默认用用户的语言、md(呼应体系报告规矩)。分开:
- **已验证的观察**(带证据 / 来源)
- **建议**(画像 delta / skill 候选 / 待删),每条给“为什么 + 后果 + 推荐”
- **只有你能决定的**(每条给选择 + 后果)

## 反模式
- 别拿一周波动当习惯(**单次过拟合**)——要重复出现。
- 别把画像堆大(**lost in the middle**)——只放稳定的,细节留原子。
- 有反证就撤销已学的模式(**反确认偏误**)。
